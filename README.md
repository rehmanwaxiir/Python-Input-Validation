# Python Input Validation

A beginner-friendly Python project that demonstrates basic input validation.

## Features
- Name validation using `isalpha()` and `isalnum()`.
- Email validation using `endswith()`.
- Phone number validation using `isdigit()`.

## Concepts Used
- Python strings
- Conditional statements (`if/else`)
- String methods
- User input (`input()`)
- Input validation

## How to Run

```bash
python input_validation.py
```
